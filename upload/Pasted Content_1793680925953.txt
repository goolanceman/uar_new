# 1. MUST FIX THE EXISTING AUTHENTICATION ISSUE FIRST

Currently, when logging into the admin application, the following issue occurs:

- The user successfully logs in.
- When navigating to admin pages, the application displays "Please sign in."
- Admin page data is not displayed.
- The authenticated session appears to be lost or is not being recognized.

**MUST investigate and resolve this issue before starting the UI redesign.**

Review the complete authentication and authorization flow across the frontend and backend.

Investigate:

- Login and logout functionality.
- Session management and token persistence.
- JWT access and refresh token handling, if applicable.
- Cookie configuration, SameSite, Secure, HttpOnly, and domain settings.
- Frontend authentication state management.
- API request interceptors and authorization headers.
- Protected routes and middleware.
- Admin role and permission verification.
- Backend authentication guards.
- Token expiration and refresh handling.
- Race conditions during application initialization.
- Data fetching before authentication initialization completes.
- CORS and credential configuration.
- Server-side rendering or hydration issues, if applicable.
- Authentication state across browser refreshes.
- Unauthorized API responses and error handling.

MUST ensure that:

1. Login works correctly.
2. Authenticated users remain authenticated when navigating between pages.
3. Refreshing the browser does not unnecessarily log users out.
4. Admin APIs return data only to authorized users.
5. Admin pages load their data correctly.
6. Unauthorized users are redirected to the login page.
7. Expired sessions are handled gracefully.
8. Users cannot access unauthorized modules.
9. Loading states are displayed while authentication is being initialized.
10. The application does not display "Please sign in" unnecessarily.

MUST identify the actual root cause, fix it in the frontend and backend wherever necessary, and verify the entire authentication flow.

Do not hide the error, bypass authentication, or use hardcoded authentication states.
